# QGIS Deployment: tools and recipes

This organization aims to centralize recognized tools and recipes for deploying QGIS in organizations, fighting against packaging issues and improving IT seamless integration to make FOSS4G a better place in large systems.

## Tools

| [QGIS Deployment Toolbelt](https://qgis-deployment.github.io/qgis-deployment-toolbelt-cli/) | [Profile Manager](https://plugins.qgis.org/plugins/profile_manager/) |

| A CLI (Command Line Interface) to perform redundant operations around a QGIS deployment, managing profiles, plugins, environment variables, start menu / desktop shortcuts and many things to rationalize installations and make end-user experience better. | Makes handling profiles easy by giving you an UI to easily import settings from one profile to another A QGIS Plugin that provides an UI to easily manage your profiles and import various settings from one profile to another. |
